This patch restores live bag updates and pickup alerts that could be delayed until entering town.

## Fixes

- Character updates are now identified by their validated payload even when the bundled RPC map assigns an unrelated callback name. Previously, these updates could be discarded before reaching the bag and loot rules, while map-entry snapshots still worked.
- Fragmented inventory updates now reassemble correctly when their fragments occupy different positions inside merged UDP packets or arrive outside a merged envelope.
- Existing alert behavior is preserved: the first inventory is a silent baseline, matching pickups alert on arrival, and an unchanged map-entry snapshot does not replay those alerts. No filter changes are required.

## Updating

Installed users can choose Settings > Check for updates, then Update and restart. Windows users downloading manually should choose `ValeCompanion-0.4.6-windows-x64-setup.exe`. Portable users should replace the executable while preserving their data folder. Save filter edits before updating, then switch maps once to establish a fresh inventory baseline.

Windows binaries are unsigned and require Npcap. Linux packages include AppImage, DEB, and RPM. Matching source, updater metadata, blockmaps, and SHA256SUMS.txt are included.

## Validation

Local typechecking and all 127 tests passed. Regression coverage reproduces a valid character update mislabeled as a vending response, verifies immediate bag changes and alerts without duplicate alerts on the next map snapshot, and checks outbound/malformed rejection. A separate regression covers mixed-envelope fragment reassembly.

Live Windows gameplay confirmed pickup alerts with a permissive rule after the routing fix; the user confirmed success. Temporary diagnostic logging was removed before release.

The release workflow gates draft assembly on Windows portable/installed-NSIS and Linux AppImage/installed-DEB smoke tests, plus updater metadata and artifact validation. RPM is built and its release metadata validated; an installed-RPM smoke test and a version-to-version in-app upgrade were not run for this patch.
