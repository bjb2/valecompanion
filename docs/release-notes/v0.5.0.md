Vale Companion now has adjustable alert volume, a movable pickup overlay with item stats, and updated market decoders.

## New

- **Alert volume:** Settings > Loot sounds now has a saved 0–100% slider for built-in and custom sounds. Existing settings default to 100%. At 0%, audio is muted without suppressing pickup history or visual notifications.
- **Pickup overlay:** Enable Settings > Pickup overlay > On-screen pickups for transparent, always-on-top notifications. Matching pickups show item icons, names, newly acquired quantities, and rule colors/tags. Visual notifications work independently of sound.
- **Equipment details:** Equipment and artifact notifications include decoded substat values, roll percentages, Chaos markers, and refinement. Stackable items retain a compact layout.
- **Stacking and positioning:** Up to five notifications fade after five seconds, with fewer cards retained when expanded stats need more room. Choose Reposition, drag the header, then Done or Lock position. The locked overlay is click-through. Position and enabled state survive restarts; Reset position returns it to the primary display.

## Fixes

- Updated capture, item, and market packages to compatible versions with the current RPC map. The old packages could leave market search requests and listings undecoded, preventing community uploads despite a healthy public API.
- Retained payload-based character recovery and the mixed-envelope fragment fix from v0.4.6.

## Using the overlay

The overlay is opt-in and follows the active loot rules. Hidden/unmatched items, the initial inventory baseline, and silent storage transfers do not trigger it. Borderless/windowed gameplay is recommended; exclusive fullscreen and Linux window-manager policies may prevent a desktop overlay from appearing above the game.

Market contributions come from browsing the in-game marketplace, not from querying the game server in the background. Accepted observations become visible in the public listings API before the next ten-minute snapshot publication.

## Updating

Installed users can choose Settings > Check for updates, then Update and restart. For manual Windows installation, choose `ValeCompanion-0.5.0-windows-x64-setup.exe`. Portable users should replace the executable while preserving their data folder. Save filter edits before updating, then switch maps once to establish a fresh inventory baseline.

Windows binaries are unsigned and require Npcap. Linux downloads include AppImage, DEB, and RPM. Matching source, updater metadata, blockmaps, and SHA256SUMS.txt are included.

## Validation

Local typechecking and all 130 tests passed. Windows desktop checks exercised the volume slider, persistence across restart, and actual audio playback at the selected volume. Native overlay checks covered always-on-top/non-focusable locked behavior, the Windows click-through flag, saved position, live pickup notifications, and Settings controls. Browser fixtures verified refinement, substat/Chaos/over-roll presentation, bounded stacking, five-second expiry, and a constrained-height viewport.

Live market browsing produced more than 5,000 successful uploads without normalization errors. The next public snapshot contained 5,883 listings and was successfully fetched through Companion's snapshot endpoint. No market-server deployment was required.

The release workflow gates draft assembly on Windows portable/installed-NSIS and Linux AppImage/installed-DEB smoke tests, plus release-file validation. Linux in-game overlay behavior, exclusive-fullscreen overlays, installed-RPM smoke, and a version-to-version in-app upgrade were not tested for this release.
