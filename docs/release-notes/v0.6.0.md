Vale Companion now enables on-screen pickups by default, recovers failed overlay windows, and refreshes map-load inventories without reannouncing owned loot.

## Changes

- **Pickups on by default:** New or unset overlay preferences start enabled. An explicitly saved off setting stays off. Change this in Settings > Pickup overlay > On-screen pickups.
- **Overlay recovery:** Enable and Reposition recreate an overlay whose renderer crashed or failed to load, instead of reopening an unusable window. Subsequent pickups can also recover an enabled failed overlay.
- **Quiet map loads:** Full `LoadCharacter_T` inventories refresh the loot baseline silently, including when decoded equipment IDs change. Subsequent pickup callbacks still generate notifications. Validated character updates recovered from stale RPC names continue to work.

## Updating

Installed users can choose Settings > Check for updates, then Update and restart. For manual Windows installation, choose `ValeCompanion-0.6.0-windows-x64-setup.exe`. Portable users should replace the executable while preserving their data folder. Save filter edits before updating, then switch maps once to establish a fresh inventory baseline.

Windows binaries are unsigned and require Npcap. Linux downloads include AppImage, DEB, and RPM. Matching source, updater metadata, blockmaps, and SHA256SUMS.txt are included.

The overlay follows your loot rules and saved preferences. Borderless/windowed gameplay is recommended; exclusive fullscreen and Linux window-manager policies may prevent a desktop overlay from appearing above the game.

## Validation

Local typechecking and all 132 tests passed. A native Windows Electron smoke check deliberately crashed the overlay renderer, recovered it through Reposition, displayed a new pickup, and verified locking and disabling. Startup checks covered missing preferences, an unset enabled property, and saved on/off choices.

The packet-consumer-to-loot-session regression covers changed equipment IDs during a map-load inventory and a subsequent genuine pickup callback. The exact live-game map-reload failure mechanism was not captured, and live in-game confirmation remains pending.

The release workflow gates draft assembly on Windows portable/installed-NSIS and Linux AppImage/installed-DEB smoke tests, plus release-file validation. Linux in-game overlay behavior, exclusive-fullscreen overlays, installed-RPM smoke, and a version-to-version in-app upgrade were not tested for this release.
