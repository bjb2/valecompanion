Vale Companion 0.6.2 refreshes item names and artwork from SpiritValers and fixes items missing from loot-rule suggestions.

## Changes

- **Box of Mastery is discoverable:** Rule autocomplete now includes Box of Mastery, and matching loot notifications show its artwork. Consumable, Material, Card, Gem, Cosmetic, and artifact category filters are suggested alongside equipment slots.
- **Refreshed bundled item data:** The shared catalog contains 628 equipment definitions, 286 cards, 130 gems, 42 artifact sets with four piece variants each, 52 materials, 28 consumables, and 1,179 cosmetic identities. Published cosmetic entries take precedence while existing supplemental cosmetic coverage is preserved.
- **Shared IDs stay separate:** Category-qualified identities prevent Mushroom material and Shroom Card, or equipment and cosmetics sharing an ID, from borrowing each other's names, artwork, market listings, bag counts, or valuations.
- **Repeatable catalog refresh:** `bun run sync:catalog` imports the released SpiritValers data and artwork; a local deployment directory is also supported. Generated assets remain bundled for offline use. Normal builds and application startup do not download catalog updates.

## Box of Mastery rule

Place this above broader rules and `Hide "everything"`, then select **Save to the game**:

```text
Show "Box of Mastery"
    Name "Box of Mastery"
    Type Consumable
    Tag MASTERY
    Color #ffd166
    Sound chime
```

Enable on-screen pickups and loot sounds in Settings as desired. Existing inventory is seeded silently; subsequent acquisitions and stack increases can notify.

## Updating

Installed users can choose Settings > Check for updates, then Update and restart. For manual Windows installation, choose `ValeCompanion-0.6.2-windows-x64-setup.exe`. Portable users should replace the executable while preserving their data folder.

Windows binaries are unsigned and require Npcap. Linux downloads include AppImage, DEB, and RPM. Matching source, updater metadata, blockmaps, and SHA256SUMS.txt are included.

## Validation

Local typechecking and all 139 tests passed, including category-collision valuation and Box of Mastery stack-delta notification regressions. Synchronization against the published website reproduced the local deployment's 2,513-entry catalog without differences. A native Electron launch verified item/type autocomplete and saving the Mastery rule; a browser smoke check verified separate material/card market rows, artwork, bag counts, inspector navigation, and prices using controlled listing fixtures.

The release workflow builds and smoke-tests native Windows and Linux packages and validates updater metadata before assembling the release. Live in-game capture and an installed-version upgrade were not exercised by the local catalog checks.
