Vale Companion 0.8.0 adds configurable, independently movable game overlays for farming and inventory tracking.

## Changes

- **F5 overlay editing:** Press F5 to reveal and unlock all overlay windows. Drag each window independently, enable the components you want, then press F5 again or choose Done. Locked windows pass clicks through to the game. Settings provides an editing button if another application reserves F5.
- **Automatic bag weight:** Display current weight, total capacity, and a fullness bar. Capacity is calculated automatically from captured character level, equipped gear, matching cards, and Carrier Gem bonuses, including the game's refinement rules. Missing snapshots or unknown catalog entries are shown explicitly rather than guessed.
- **Tracked item counts:** Select up to three item types from your bag in Settings or overlay edit mode. Counts combine stacks and remain at zero when a selected item leaves an observed bag. These are current holdings, not cumulative pickup totals.
- **Gold per hour:** Keep gross earnings per active session hour visible while farming. Uses the existing Gold session, excludes the starting balance, and identifies waiting or paused sessions.
- **Saved layouts:** Component visibility, tracked items, and individual window positions survive restarts. Reset all positions restores the default layout; monitor changes keep windows within available displays. Existing pickup overlay preferences and positions are preserved.
- **Catalog refresh:** Updated the published SpiritValers catalog to 2,535 entries: 22 additions and 21 metadata changes, with no removals. Refreshed the associated bundled artwork.

## Updating

Installed users can choose Settings > Check for updates, then Update and restart. For manual Windows installation, choose `ValeCompanion-0.8.0-windows-x64-setup.exe`. Portable users should close Companion and replace the executable while preserving their data folder.

Pickups remain enabled by default. Enable the new components under Settings > Game overlays. F5 temporarily reveals disabled components for editing without changing the master visibility switch; turn on On-screen overlays to keep selected components visible during play.

After restarting Companion, inventory and capacity appear when a character/inventory update is captured. Gold tracking needs an authoritative gold balance. When attaching mid-session, changing maps or reconnecting can establish fresh inventory and RPC-link state. Bag-weight rules and bonus sources were verified against SpiritVale 0.33.0 Early Access.

Borderless/windowed gameplay is recommended; exclusive fullscreen and Linux window-manager policies may prevent desktop overlays from appearing above the game. Windows binaries are unsigned and require Npcap installed separately. Linux downloads include AppImage, DEB, and RPM. Matching source, updater metadata, blockmaps, and `SHA256SUMS.txt` are included.
