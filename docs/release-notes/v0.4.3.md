This patch gives grimoires their own inventory category, making them easier to find among equipment.

## Changes

- Grimoires now appear in a separate **Grimoires** section when grouping Bag or Storage by category.
- The new section supports item counts, collapsing, remembered collapse state, and automatic expansion while searching.
- `Type Grimoire` filter rules and equipment-style market valuations remain unchanged.

Thanks to @Morta1 for PR #10.

## Updating

Installed users can choose Settings > Check for updates, then Update and restart. Windows users downloading manually should choose `ValeCompanion-0.4.3-windows-x64-setup.exe`. Portable users should replace the executable while preserving their data folder.

Windows binaries are unsigned and require Npcap. Linux packages include AppImage, DEB, and RPM. Matching source, updater metadata, blockmaps, and SHA256SUMS.txt are included.

## Validation

112 tests, typechecking, and the local build passed. Local renderer checks covered category counts, collapse persistence, search expansion, ungrouping, and Storage. Filter matching and market valuation were checked separately, and the user verified the desktop application locally. Windows and Linux package smoke tests and updater-file checks run before publication.
