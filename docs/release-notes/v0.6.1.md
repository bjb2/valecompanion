Vale Companion 0.6.1 records complete printed stat values when contributing equipment listings to ValeMarket.

## Changes

- **Complete market stats:** Market uploads now resolve printed equipment values from the same build-scoped item-to-pool map as Loot. Items whose package metadata omitted a roll-pool classification no longer publish named stat lines with missing values.

## Updating

Installed users can choose Settings > Check for updates, then Update and restart. For manual Windows installation, choose `ValeCompanion-0.6.1-windows-x64-setup.exe`. Portable users should replace the executable while preserving their data folder.

Windows binaries are unsigned and require Npcap. Linux downloads include AppImage, DEB, and RPM. Matching source, updater metadata, blockmaps, and SHA256SUMS.txt are included.

Previously published missing values cannot be reconstructed because the original observations did not include raw rolls. Those listings remain unchanged until they expire, are relisted, or receive a higher game listing version. New observations made by 0.6.1 include every value that the build-scoped pool snapshot can decode.

## Validation

Local typechecking and all 133 tests passed. The market-normalizer regression reproduces an Azure Antlers listing whose MP and DEF values were previously omitted, fails without the fix, and passes with the authoritative Headgear mapping. A native Windows development launch rebuilt the collector, reported version 0.6.1, opened the Electron window, and reached collector readiness with Npcap.

Packaged Windows and Linux release artifacts, installed upgrade behavior, and live publication of a newly observed corrected listing remain release checks.
