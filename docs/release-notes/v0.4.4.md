This patch restores rule-editor autocomplete and fixes printed substat decoding against Spirit Vale 0.32.0 Early Access.

## Changes

- Added context-sensitive rule suggestions for item names, types, stats, comparisons, and display/sound options. Use Ctrl+Space to request suggestions, arrows to choose, Enter/Tab to insert, and Escape to dismiss.
- Numeric suggestions are explicit-only, completed values do not capture Enter, and moving the caret does not reopen suggestions. Popup navigation scrolls only the suggestion list, not the surrounding rules editor.
- Corrected Eyewear and Back to use the Headgear roll pool, restoring flat MDEF and MATK decoding for items such as Azure Antlers. Shields use the Chest pool.
- Replaced incomplete roll tables and stale item-pool selection with all nine pools and 726 equipment mappings verified against live game build 25433400, including 13 weapon overrides missing from the previous bundled catalog. Printed values now follow the client's single-precision scaling and rounding.
- Expanded the README with supported filter syntax, printed values versus roll percentages, first-match precedence, grouped conditions, and practical examples.

## Updating

Installed users can choose Settings > Check for updates, then Update and restart. Windows users downloading manually should choose `ValeCompanion-0.4.4-windows-x64-setup.exe`. Portable users should replace the executable while preserving their data folder.

Save filter edits before updating. After restarting Companion, switch maps in game to capture a fresh inventory with the corrected stat values. Specific-item rules must still precede broader matching rules, including favourites.

Windows binaries are unsigned and require Npcap. Linux packages include AppImage, DEB, and RPM. Matching source, updater metadata, blockmaps, and SHA256SUMS.txt are included.

## Validation

Local typechecking and all 123 tests passed. Regression coverage includes both Azure Antlers examples, flat versus percentage MATK, equipment-pool boundaries, and client rounding. An asset-backed decoder check verified 6,458 equipment roll values across 726 definitions plus all four non-attribute artifact roll values. Browser checks covered completion insertion, dismissal, numeric Enter behavior, and stable editor geometry during popup navigation.

The release workflow gates publication preparation on Windows portable/installed-NSIS and Linux AppImage/installed-DEB smoke tests, plus updater metadata and checksum validation. RPM is built and its release metadata validated; an installed-RPM smoke test and a version-to-version in-app upgrade were not run for this patch.
