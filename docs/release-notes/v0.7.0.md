Vale Companion 0.7.0 brings its protocol libraries under local maintenance and fixes missing game icons after reopening the Windows portable app.

## Changes

- **Locally maintained protocol libraries:** Capture, item lookup, market decoding, and logging are now included as editable source in Companion. Builds no longer depend on the discontinued `@kar-mi/spirit-vale-tools-*` packages. Existing RPC definitions, item data, and stat names are preserved.
- **Independent RPC-map updates:** One checked-in JSON map drives live capture and replay. Source-maintenance commands export, validate, compare, and atomically import verified maps, including supported datamine exports. Binary-pair fingerprinting, same-build corrections, and rollback are documented in the README. This is an update workflow, not an automatic binary-to-RPC extractor.
- **Portable icons stay available:** Opening the portable executable again no longer lets the second launcher delete the running instance's resource files. Each launch gets its own extraction directory; Electron still brings the existing window forward.
- **Stronger packaged checks:** The renderer must decode game artwork from each catalog category. Windows portable smoke testing also repeats those checks after a second launch and cleanup, using fresh image URLs rather than cached images.
- **Reproducible source releases:** The source archive includes the owned packages, their original AGPL licenses, upstream revision provenance, RPC data, and maintenance tooling. Independent data snapshots retain their own build identities when only the RPC map changes.

## Updating

Installed users can choose Settings > Check for updates, then Update and restart. For manual Windows installation, choose `ValeCompanion-0.7.0-windows-x64-setup.exe`. Portable users should close Companion and replace the executable while preserving their existing data folder. No profile or filter migration is required.

Windows binaries are unsigned and require Npcap installed separately. Linux downloads include AppImage, DEB, and RPM. Matching source, updater metadata, blockmaps, and `SHA256SUMS.txt` are included.

## For maintainers

From the source checkout:

```sh
bun run rpc:map --help
bun run rpc:map export ../rpc-before.json
bun run rpc:map check ../rpc-candidate.json
bun run rpc:map diff ../rpc-candidate.json
bun run rpc:map import ../rpc-candidate.json
bun run check
bun run build
```

Rebuild and restart after importing. New wire definitions still require verified analysis of matching game binaries and assets. Character/storage layouts, market schemas/stat IDs, and printed-stat pools remain separate maintenance responsibilities. Keep community contribution disabled while testing an unverified map.

## Validation

Local typechecking and all 143 tests passed during implementation. An isolated workspace containing only the owned packages proved parity with the installed libraries, map replacement through Companion's actual decoder, build-fingerprint propagation, rejection of malformed imports without replacing the active map, and rollback. The published catalog refresh reproduced the existing 2,513 entries without added, removed, or changed entries.

Windows packaged startup, game-artwork decoding, and the portable double-launch regression passed. Bag loading and the corrected portable icons were also confirmed in live game use. The release workflow builds and smoke-tests native Windows and Linux packages and validates updater metadata before assembling the release. Full Linux gameplay, installed RPM smoke, and a version-to-version in-app upgrade are not covered by the local checks.
