This patch fixes blank inventory tabs and artifact-category filter rules.

## Changes

- Restored Bag and Storage inventory panels. Their tabs could show an item count but no contents while the Rules preview continued to work. Search, grouping, Matches filtering, and item inspection are available again.
- Fixed `Type Artifact` to match Runes, Jewels, Scrolls, and Relics. Explicit subtype rules still work, and rule explanations use the same category matching.
- Existing artifact rules using `TopRolls` and `AnyOf` need no syntax changes. `TopRolls >= 3` still requires three displayed-max lines; an `AnyOf` primary-stat condition remains independently required.

## Updating

Installed users can choose Settings > Check for updates, then Update and restart. Windows users downloading manually should choose `ValeCompanion-0.4.5-windows-x64-setup.exe`. Portable users should replace the executable while preserving their data folder. Save filter edits before updating.

Windows binaries are unsigned and require Npcap. Linux packages include AppImage, DEB, and RPM. Matching source, updater metadata, blockmaps, and SHA256SUMS.txt are included.

## Validation

Local typechecking and all 124 tests passed. The exact artifact rule is covered against a decoded Corporeal Rune, including rejection of equipment, insufficient top rolls, and a missing qualifying primary stat. Browser checks with fixture inventory verified Bag and Storage rendering, Bag search, Matches filtering, category collapse/reopen, and item inspection.

The release workflow gates draft assembly on Windows portable/installed-NSIS and Linux AppImage/installed-DEB smoke tests, plus updater metadata and artifact validation. RPM is built and its release metadata validated; an installed-RPM smoke test and a version-to-version in-app upgrade were not run for this patch.
